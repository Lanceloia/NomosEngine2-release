# 对外展示前的检查

这页是发布操作清单，不是新的引擎开发 Goal。当前展示内容已经足以让读者核对有限成果，
无需等待通用 TRPG、LLM DM 或所有设想完成才投递。
最新本地安装与演示结果见[展示准备记录](SHOWCASE_READINESS.md)。

## 内容

- 首页能说明动机、当前实现和未来边界；首次读者从[项目导览](PROJECT_TOUR.md)进入。
- 三项演示的命令、预期差异、输入文件和原始证据都有入口。
- 个人贡献如实归因，不将 Agent 生成的代码全部认领为个人手写。
- 权利条款与 M1 署名保留；不要把整仓库说成已有统一开源许可证。
- 本地安装／测试记录与远端 CI 结果分开，不为未运行的环境放绿色通过标记。

## 发布

本地发行仓库目前没有配置 Git remote，也没有已完成的 GitHub CI 运行可供引用。
创建或指定对外仓库、选择可见性、设置 remote 和首次 push 仍由项目发起者确认；
本清单不代替授权发布，不自动复制研究仓库或个人简历材料。

首次推送后核对：首页与 Markdown 相对链接、Actions 的实际运行结果、权利文件与署名。
首次 CI 失败时按具体命令修复，不把存在 workflow 等同于已经通过。
然后把实际仓库地址放入简历；需要时可附三个实验中的一个短录屏。
已有旧 GIF 不作为当前展示门，不为了投递继续追求动画评分。

## 投递后的维护

先记录真实读者的问题，再安排下一批工具或文档改进。
面试准备与长期开发分开：讲解一条实际编译路径、一次原子回滚、一个失败反例和一次规则编辑实验，
比临时堆出更多功能更容易证明理解。笔试复习另开计划，不塞入项目发布清单。
