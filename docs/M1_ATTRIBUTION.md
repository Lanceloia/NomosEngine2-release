# M1原作与有限改编

本仓库M1作者资产改编自Pepijn与Willem-Jan的 *Thawed Through the Everflame*，
1.1版，2025年。原研究仓库将原作和改编内容标明为
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；本提取保留该条款，
不将作者资产纳入引擎代码的保留权利说明。

改编包括有限区域/距离表、可重放种子骰、动作费用、局部观察与信息获取、
居民有限自主选择、寒冷事件和正常终止条件。它不是精确连续几何，也不是原作全部电子化。
本轮核心重建可能修复错误结算；行为变化必须记录，不能为保留旧结局恢复缺陷。

本仓库不包含原作PDF或中文整本译稿。其上游来源与改编过程保留在研究仓库：
`docs/reference_adventures/m1_thawed_through_the_everflame/`与
`packages/thawed_everflame_remaster/`。本行是来源记录，不是运行依赖。
