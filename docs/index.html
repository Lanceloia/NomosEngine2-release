为什么从剧情走向规则？

作者创作世界允许发生什么，玩家选择实际发生什么，系统依据规则结算。新版串起这一愿望、工具职责与狼人杀实验，再走进 M1 冰宫，看看有限永焰、地面观察与居民回应怎样改变下一步选择；新配音正在准备。

从创作愿望到可运行的工具

预写剧情难以覆盖不断出现的选择。TRPG 通过规则、世界设定、主持人的判断与玩家即兴，形成不同经历。我们希望把世界规则和结算建立为可维护的系统，让创作者逐步减少穷举剧情分支的负担。

目前已建立声明式作者语言、C0 编译器、K0 执行内核和 T0 行动见证检查器。狼人杀与 M1 是检验这套方法的世界；快速设计与验证游戏原型，是工具当前的实际用途。

也可以先写一个精彩故事

直接设计完整规则并不容易，但作者可以先描述一次营救、反转或险境脱身。T0 的长期目标，是帮助作者从这些故事探索支持它们的事实、能力与规则，再用真实运行检验。当前已实现行动见证检查；故事理解与规则推导是后续方向。故事为创作提供样例，玩家仍能选择自己的行动。
