# 原始实验记录

这里保存运行输入、逐步结果和采集摘要。首次阅读请先看中文说明：
[禁止自救](../SHOWCASE.md)、[共同袭击](wolf-vote/README.md)、
[换职业与扩人数](world-edits/README.md)。

`self-heal-predicates-v1/` 与两项实验的 `evidence-predicates-v1/` 是谓词整理后的采集；
较早的 `result.json`、`manifest.json`、`evidence/` 与 `historical-inputs/` 保留旧证据，
用于核对输入摘要和前后记录，不是当前作者示例或兼容编译链。

摘要说明文件一致性，不是认证签名。历史 manifest 可能记录研究机的绝对路径、
当时的工作树状态或旧媒体；这些字段不要求另一台机器相同，也不作为安装路径。
旧动画、分镜、渲染器和体验评审不随此发行版保留，原始采集摘要不为清理而改写。

工具默认运行当前代码、只在内存编辑。要保存新的当前结果，使用 `--record` 和
尚不存在的目标目录；不要覆盖旧报告或把它改署为当前版本。
工具的实际运行方式见各实验说明，报告核对测试不替代引擎结算测试。
