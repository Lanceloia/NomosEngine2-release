# 中文字形

两份 WOFF 从 Noto Sans SC 可变字体按新版动画／首页实际文本生成，使用 fontTools subset。
`chinese.woff` 覆盖画面、字幕和控件；`site-chinese.woff` 覆盖项目首页。
保留权重信息，许可见 [OFL](OFL.txt)。
原字体为 [Google Fonts 的 Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)；
本轮取用的可变TTF摘要为 `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`。
字体许可独立于项目原始材料权利。
