## 影片讲什么

从支援 TRPG 的愿望出发，介绍作者声明世界规则、C0 编译、K0 结算、T0 路线验证的分工。
三个狼人杀实验分别检查限制、结算与人物配置；M1 冰宫原型展示规则的组合。
最后介绍未来的创作与主持工具，以及项目的人类决策和 AI 实现分工。

M1 使用 2026-10-11 采集的五次真实操作：永焰5→4、复查冰面有冰→无冰，
以及邀请后本人实际听见两名居民答复。画面逐项聚焦这些变化。
影片中的狼人杀图示整理自[已有真实实验](../../PROJECT_TOUR.md#先看三个实验)。
