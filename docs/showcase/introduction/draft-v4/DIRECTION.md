# 新版分镜与素材安排

## 叙事主线

玩家的新尝试 → TRPG 启发 → 作者／玩家／系统的分工 → C0/K0/T0 的实现方法 →
规则与世界编辑实验 → M1 的规则组合 → 当前用途与长期目标 → 真实贡献。

先解释为什么要建立工具，再解释工具名称。每个实验的转场都回答它为自由探索世界验证了什么。

## 制作边界

本轮有声版需要新配音。先输出完整口播、可暂停选章的字幕动画及无声 MP4 预演，
按阅读速度估计时间，供审核节奏。收到新版录音后再按实际音轨调整时间和字幕。
旧 film-v3 有声片保留历史链接；公开首页优先展示校准后的字幕预演。

不重新运行世界来制作画面，不改变旧实验报告或 M1 的原始响应。
首两段动图强调问题和创作关系，工具段解释分工，真实素材段展示玩家选择留下的变化。
