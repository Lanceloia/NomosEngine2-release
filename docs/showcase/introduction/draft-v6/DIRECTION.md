# 录音前分镜：让 M1 的选择可理解

## 本轮修订

M1 从开场、地图、若干结果的快速剪辑，改成“局面 → 取舍 → 观察 → 人物回应 → 下一步选择”。
两局实录用“另一段记录”分开；每次只放大一个反馈，不把充能、地图和人物日志同时塞进画面。
C0/K0 拆句解释，T0 先讲创作动机，再展示当前运行核对和下一阶段。

| 镜头 | 画面与焦点 | 依据与衔接 |
| --- | --- | --- |
| 玩家新尝试／TRPG | 保留原问题与四方关系动画 | 愿望先于工具名 |
| C0／K0 | 声明 → 编译 → 开局 → 行动 → 后果逐句出现 | “启动一局”与“每次提交”分开 |

## 画面节奏与媒体检查

M1 口播约占一分半至两分钟，实际时长以导出的时间线为准；录音后重新对齐音轨。
M1镜头切换依据该句的时间；口播提到充能、地面和回应时展示对应内容。
工具图示保持顺序淡入，实际录音后再逐句对齐。
视频寻帧串行等待完成。预览截图、浏览器与MP4使用相同准备入口；M1每个关键句另存两桌面截图，核验非空与可读性。
原始截图与实录保持原文件，放大裁切与规则示意在动画中进行。示意与“实录”分标。
采用一个浏览器、两编码线程；制作完关闭自己的浏览器与编码器。不启动世界或性能门。
