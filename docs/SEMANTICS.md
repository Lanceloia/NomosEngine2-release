# 选定语义与失败边界

本仓库维护有限声明式语言，不承诺任意 Python 或完整 UFO。
现行 Source 只有 `c0.owner_graph.v6`，没有旧版本回退。
Lib/Ports/Source 是唯一现行作者链，历史语言不作为备用编译入口。

## 层的责任

| 层 | 负责 | 不负责 |
| --- | --- | --- |
| Lib/Ports/Source | 类型、规则、绑定、显式权限、候选和控制策略 | 固定剧情序列、直接操作私态 |
| Assets | 一局开局与种子 | 运行中补状态、改规则 |
| C0 | 声明检查、IR、绑定、开局、有限投影及控制 | 宿主补算结局、隐式授权 |
| K0 | 当前态准入、贡献、因果/due、事务、隔离和来源 | 领域知识、UI、恶意代码沙箱 |
| T0 | 同一 Program 中实际执行有限见证 | 另建模拟器、证明所有路线不可达 |
| UI | 显示授权信息、提交当前选择 | 私态泄漏、伪造发生 |

## 承诺

1. 文件冻结；非法声明拒绝；Compile/Bind 无 Assets，Start 完整检查后原子建局，Run 不重读文件。
2. 名义类型不因结构相同互换；显式 Object specialization 只在已选合同内代入。实体 ref 属于本局真实 family/owner，形成来源不是身份。
3. 每个 owner 的读、构造、写路径独立。同型参与者、纯定义或输出族不扩大权限。
4. 类型、阶段、非空证明和词法作用域受检；运行只接受 checked IR。查询和分支有序短路，输出子集保持声明顺序及首错。
5. 世界写入只由真实 K0 发布；菜单、预测、标签不写世界或掷骰。形成/到场/交付不自动产生正文知识。
6. 效果、产品、形成身份与来源原子生效。未选合并不允许静默覆盖；有序微步重读候选态并检查不变量。
7. 当前为线性事件跃迁及有限行动值控制。advance/due 是 K0 来源，defer 是 C0 控制。Appraisal 提议仍经 K0 重核。
8. 正常终局在根闭包结束原子封闭，后缀不形成身份或抽骰；封闭可读，与拒绝/fatal 分开。
9. 专用化只用封存元数据，不缓存当前值或准入成功。验证复用限同次实际值及依赖；native 回调隔离副本不能修改权威状态。

## 结果分类

| 结果 | 世界与后续 |
| --- | --- |
| Compile/Bind 失败 | 无 Program；修声明、类型、权限或绑定 |
| Start 失败 | 无可见半局；修开局 |
| 候选缺失/投影故障 | 无写入；不推出全局不可达 |
| K0 not-admitted | 本次零写，可继续 |
| settlement defect | 本次原子回滚，Session fatal |
| 控制预算结束 | 保留实际前缀，可继续；T0 标 not-met-within-bound |
| 正常终局 | 合法前缀发布并封闭，未执行后缀不冒称成功 |

T0 只检查给定规则/开局中这一条实际见证，不保证根因唯一。
时间/行动值、occurrence 与 C0 控制历史各有来源，不能混成一种整数。

精确写权、状态隔离与候选/准入的区别见[设计取舍](DESIGN.md)。
Action/Event 名称属于不同入口类别；输出保持声明顺序和首错，形成来源不规定
写 owner 的数量。当前形成注解只支持有限 scheduler/trigger 对应，不提供通用
多 scheduler 或任意共享 event type 的来源证明。

## 排除

完整 UFO、Quantity/Quality/Relator 全动态语义、公开跨局身份/恢复、连续空间/时间、
分支历史、通用同波自动 merge、多人认证、LLM 决策、剧情或心智求解不在本门。
K0 Collective 的有来源入集有内核测试，不代表 C0 已有完整 Collective 作者语言。
受信 Python 原生端点不是恶意插件沙箱。

检查入口见[设计与反例](DESIGN.md)、[执行后端](EXECUTION_BACKEND.md)和
[测试指南](TESTING.md)。未测组合不写成保证。
